# TIG Rotator Controls

The low-voltage controller subsystem of the DIY TIG welding positioner: the GUITION JC4880P443C ESP32-P4 touch board, its speed pot, direction switch, foot pedal (switch plus ADS1115 pot), conditioned E-STOP input and the DM542T signal terminal. Motor power, the stepper, gearbox and the grounded metal enclosure are outside this package.

Open `index.html` for the overview, or go straight to `guide/index.html` to build it.

| File | What it is |
| --- | --- |
| `guide/index.html` | Assembly guide: 29 illustrated pages, drawn to scale |
| `guide/guide.pdf` | Assembly guide, printable: A4 PDF |
| `files/bom.csv` | Parts list: Every part with a search term and a price |
| `shopping/index.html` | Shopping list: Every part with what to check and shop searches |
| `files/drawings/index.html` | Drawings: Wiring plan, dimensioned case drawing and pin map |
| `files/firmware/platformio.ini` | Firmware: PlatformIO project with a bring-up test |
| `files/project.json` | The source of truth every other file was generated from |
| `files/parts/` | Definitions of the parts this project adds or corrects; keep this folder next to `project.json` when rebuilding |
