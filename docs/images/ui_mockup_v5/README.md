# TIG / ROTATOR — dark orange design proposal

30 illustrative views cover all 22 registered screen types, plus state variants, the safety overlay and input keyboards. Screen dimensions: 800 × 480. All UI labels are English.

Open index.html to browse, all_screens.svg for the vector overview, or overview.png for a contact sheet. Each screen has editable SVG and a PNG preview. The chosen direction uses a large orange value surface, dark graphite panels, rounded controls, a wide primary action and explicit red fault/stop states.

These are design proposals. Calibration verification gates, keyboard flows and some navigation details are proposed changes, not confirmation of current firmware functionality. Values are illustrative. Hardware safety still requires physical verification. No firmware was changed or uploaded for this design task.

Regenerate with python scripts/generate_ui_mockup_v5.py (uses the V3 inventory). The gallery notes record individual workflow proposals.
