# v2.2.0 - Idle screen saver and flat UI refinements

This release adds an optional screen saver in the V5 graphite/orange design, with English text, slow rotator-marker movement and no shadows. It also includes the motion, input and storage corrections made since v2.1.1. Hardware target: **GUITION JC4880P443C 4.3-inch ESP32-P4 touch display board**.

![Screen saver - actual LVGL capture](https://raw.githubusercontent.com/catorendal-a11y/DIY-Welding-Positioner-ESP32-P4/v2.2.0/docs/images/ui_runtime_v5/SCREEN_SAVER.png)

## Screen saver and UI

- **Settings > Display > Screen saver after:** OFF, 30s, 1m, 2m or 5m. SAVE retains the choice; PREVIEW opens it immediately at normal brightness.
- The first touch only wakes the display, consuming the entire press until release. A second deliberate touch operates the UI. Touchscreen, USB mirror and simulator share this filter.
- Motion, stopping, pulse pauses, commissioning, editing, stale status, pending/failed saves and fault overlays remain visible. Waking preserves the previous page and restores configured brightness.
- Larger Motor Configuration cards, exact RPM/acceleration entry, validated drafts and edit locks during save/apply.
- Shared full-screen input panels with a visible CANCEL button. Fault/E-STOP takes priority over keyboards.
- Improved text placement, clearer disabled controls and immediate button-state colors. Typed LVGL observers skip unchanged status updates and clean up on screen/theme reconstruction.

## Motion, inputs and storage

- Cancel countdown starts across STOP, faults, stale control and navigation. Reset cannot renew an old START.
- Validate motion ranges, signed step counts and configuration/program requests; re-clamp Jog at execution.
- Supervise Pulse stopping and finite Step moves independently of the control loop, using completion budgets based on the commanded rate and acceleration.
- Retain the 20 Hz operational floor, expose the geometry-dependent minimum RPM and reject infeasible commands instead of silently increasing speed.
- Preserve program direction and analog-input takeover semantics. Validate full serialization, NVS byte counts, bounded blobs and legacy migrations; show save receipts.
- Bound USB receive work and partial-frame lifetime, release remote pointers on focus loss and replace unsupported LVGL heap monitoring with ESP-IDF statistics.

LVGL remains **9.6.0**, FastAccelStepper remains the pinned upstream **1.4.0** commit and the existing single-owner motion architecture is retained.

## Validation and hardware status

Release assets are packaged from the exact tagged commit's successful master CI run. Validation includes **459 native/control/speed/storage tests**, packaging regressions, upstream FastAccelStepper RMT checks, Linux/Windows simulator self-tests, a zero-failure layout audit and all three firmware builds. Screen-saver regression uses actual LVGL pointer hit testing over START and checks held-touch consumption, timeout/OFF, external starts, fault priority, storage failures and reconstruction.

The pre-release functional build at commit `673e078` was uploaded to the owner's ESP32-P4 on 2026-10-03; flash data verified and no serial error output was observed during a subsequent 10-second check. On 2026-10-03 the owner confirmed that all currently assembled controller functions work. Pedal/ADS1115 wiring and commissioning are unfinished and intentionally deferred. This is owner-reported functional confirmation; no quantitative stop-time, calibration-accuracy, rendering or HF test measurements were supplied. The released binaries preserve the validated tag commit; the owner feedback refers to the same functional code flashed before the version-only release bump. A single axis has no encoder feedback; displayed speed/progress are calculated.

Update 2026-10-05: pedal/ADS1115 commissioning was subsequently completed on the owner's hardware — the boot scan detects the ADS1115 at 0x48, and GPIO33 start/stop plus analog pedal speed are owner-confirmed working — using the master runtime source-selection fix (commit c4ea129). The released v2.2.0 binaries are unchanged.

## Upgrade

Existing settings and programs are retained with the matching partition layout. The saved dim timeout becomes the screen-saver timeout; **OFF** keeps automatic activation disabled. Existing installations do not need to repeat setup merely for this update. On the simulator, automatic activation starts OFF; use PREVIEW or select a timeout and SAVE.
