# v2.2.1 - Pedal runtime source selection

This patch release makes the foot pedal work in every hardware configuration and records its completed commissioning on the assembled machine. Hardware target: **GUITION JC4880P443C 4.3-inch ESP32-P4 touch display board**.

## Fixed

- **Foot-pedal enable no longer locks out motion when no ADS1115 is present.** An enabled pedal with no ADS1115 detected at boot now runs switch-only: GPIO33 start/stop with panel-potentiometer speed. Previously the missing analog input blocked every start, and a running session latched a PEDAL INPUT fault.
- The analog pedal source is selected from runtime ADS presence (`speed_ads1115_pedal_present()`) instead of the `ENABLE_ADS1115_PEDAL` compile flag. A detected ADS1115 that stops delivering fresh samples still blocks motion and latches PEDAL INPUT — the stale-input safety behavior is unchanged.
- Wiring diagram rev 2.7: the ADS1115 is drawn as the physical 10-pin module in silk pin order, with the required **ADDR → GND** connection for I2C address 0x48, and the pedal/I2C routing is drawn clear of the card.

LVGL remains **9.6.0** and FastAccelStepper remains the pinned upstream **1.4.0** commit.

## Downloads

- [Portable Windows x64 simulator](https://github.com/catorendal-a11y/DIY-Welding-Positioner-ESP32-P4/releases/download/v2.2.1/welding-positioner-v2.2.1-simulator-windows-x64.zip): extract all files and open **Start Simulator.cmd**. No hardware or development tools are required.
- Firmware bundles: **release** for normal use, **debug** for diagnostic logging and **mirror** for the USB live viewer. Each ZIP includes flashing instructions, bootloader, partition table, OTA initialization, build metadata, license notices and checksums.
- Standalone `.bin` downloads contain the application only and belong at **0x10000**; they are not complete flash images. Follow the bundled instructions.
- Reviewed wiring SVG archive and SHA-256 checksums are included.

## Validation and hardware status

- **453 native/control/speed/storage test cases** pass, including two new regression tests covering the pedal chain: switch-only fallback without an ADS1115, and the stale-sample block when a detected ADS1115 fails.
- Release, debug and mirror firmware compile from the tagged commit.
- Flash-verified on the owner's ESP32-P4 (COM3) on 2026-10-05: the boot I2C scan detects the ADS1115 at 0x48 (with GT911 at 0x5D/0x14 and the ES8311 codec at 0x18), and the owner confirms GPIO33 start/stop and analog pedal speed work on the assembled machine.
- No quantitative stop-time, calibration-accuracy or HF measurements are claimed. A single axis has no encoder feedback; displayed speed/progress are calculated.

## Upgrade

Existing settings and programs are retained with the matching partition layout; a standard application-image update is sufficient. Pedal control still must be enabled in **Settings > Foot pedal** (default OFF) and released at least 50 ms before pressing so the interlock can arm. With no ADS1115 connected, the panel potentiometer sets the speed; with an ADS1115 present, the pedal potentiometer sets the speed and pressing the pedal starts motion.
