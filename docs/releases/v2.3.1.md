# v2.3.1 - Operator feedback and test fixes

This release makes refused actions explain themselves and removes test code that had drifted from the firmware. It requires no hardware changes. **These changes have run in the simulator, not on the assembled machine. The owner's machine test on 2026-11-04 covered v2.3.0. Run the checks below before welding with it.**

## Changed on the machine

- A confirmed program start that gets blocked shows **PROGRAM BLOCKED** with the reason. It was only logged.
- REBOOT explains why it is refused while the machine runs or a save is pending. It did nothing visible.
- An invalid Step angle or diameter keeps the keypad open and shows the allowed range. It closed without a message.
- Jog no longer changes the manual direction.
- The screen saver uses the selected accent color.
- The fault overlay heading names every fault. HMI STALE, SPEED POT, STORAGE and others showed MOTION LOCKED.

## Internal

- State transitions and motion limits have one definition, shared by the firmware and the native tests. The old test copies had drifted: no ENABLING state, and rate and negative-angle behavior the firmware no longer has.
- 31 native tests that only checked those copies are removed, and tests for ENABLING and rate rejection are added. That is why the total went from 511 to 484.
- The simulator covers HMI STALE, SPEED POT, STORAGE and UNEXPECTED RESET, and the changes above. `simulator/main.cpp` is split by theme.
- CI runs cppcheck with a probe that proves it reads the source. Actions are pinned to commits, and Dependabot proposes updates in one monthly group.
- The unused `lib/esp_lcd_ek79007` and `sdkconfig.defaults` are removed.

## Known limits

These cannot be solved in firmware alone:

- An open E-STOP wire reads as healthy, and E-STOP acts through the MCU and the driver ENA input. It does not disconnect motor power.
- A floating pot wiper is not detected, and the analog pedal is not jump-checked.

## Validation and hardware status

- **484 native/control/speed/storage/safety test cases** and the packaging tests pass.
- Linux and Windows simulator self-tests and layout audits pass.
- Release, debug and mirror firmware compile. Cppcheck finds no high or medium defects.
- **Not tested on the machine.** The owner reported v2.3.0 tested on the assembled machine on 2026-11-04, including TIG HF. No stop-time or calibration-accuracy measurements are claimed.

Check on the machine after flashing:

1. Jog in both directions, then confirm the manual direction is unchanged.
2. Enter an invalid Step angle and confirm the keypad stays open with the range.
3. Start a program above the RPM cap and confirm **PROGRAM BLOCKED** shows the reason.
4. Press E-STOP and confirm the overlay, reset and motor stop behave as before.

## Upgrade

Existing settings and programs are retained with the matching partition layout, and a standard application-image update is sufficient.
