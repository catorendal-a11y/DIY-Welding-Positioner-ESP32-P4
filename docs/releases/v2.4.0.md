# v2.4.0 - Reworked screens and logic fixes

This release reworks the screens for gloved, at-a-glance use, makes the fault screen say what to do, and fixes a timestamp race and eight screen-logic defects. It requires no hardware changes. **The owner flashed this code on 2026-11-10 and confirmed that it boots and that the screens display correctly. Motion, pedal and calibration were not re-tested on it. Run the checks below on your own build before welding with it.**

## Changed on the machine

- **Every screen** is rebuilt: orange marks choices and actions only, labels use plain words, and every header shows the live machine state as a filled pill.
- **Fault screen:** the next action leads, for example "Release the E-STOP button.", with the cause below it. The banner is red while something blocks the reset and amber with READY TO RESET when only the reset is missing. A released E-STOP is titled E-STOP RELEASED.
- **Main:** - and + sit beside the speed value instead of next to Start, and use 0.001 RPM steps below 0.1 RPM. A Programs button is on the main screen, and elapsed time shows during motion.
- **One action slot:** Pulse, Step, Countdown, Jog, Calibration and the setup check show Start while idle and Stop as soon as anything moves.
- **Screen saver:** states "Motor stopped" and shows the set speed and direction.
- **Edit program:** the Available switches are full size.
- **Calibration:** the jog buttons are named Jog CCW and Jog CW, and the diameter field has a caption and an edit icon.
- **Diagnostics:** larger text.
- Reset step on the Step screen is removed.

## Fixed

- A heartbeat, pedal sample or jog renewal stamped by another task just after the checking task read the clock no longer counts as 49 days old. This rare race could stop a weld with HMI STALE or PEDAL INPUT, or drop a held jog.
- The program editors no longer accept a speed below what the motor can run at the program's diameter. Such a program could be saved but never started.
- Countdown keeps "Start blocked" on screen when the start is refused after the countdown.
- Step re-limits the speed after a diameter change, and - no longer raises a typed angle below 5 degrees.
- Display settings: Back without Save restores brightness, appearance and accent.
- Calibration: a diameter entered and then abandoned no longer stays active.
- Motor configuration: the stop angle follows an edited roller diameter and gear ratio.
- Stop after a soft start uses the configured stop ramp.
- The speed pot or pedal no longer overrides a speed set on the screen until it is moved or reaches that speed.
- Lowering Max RPM no longer rewrites a saved program.
- Manual direction, pulse times, step angle and jog speed survive a restart.

## Known limits

- The Pulse screen keeps its own speed and does not read the machine target when opened.
- Pulse programs have no direction control. Set the direction in the Continuous or Step settings.
- Cancel during a pending program save leaves the editor but does not undo the save.
- An open E-STOP wire reads as healthy, and E-STOP acts through the MCU and the driver ENA input. It does not disconnect motor power.
- A floating pot wiper is not detected, and the analog pedal is not jump-checked.

## Validation and hardware status

- **492 native/control/speed/storage/safety test cases** and the packaging tests pass.
- Linux and Windows simulator self-tests and layout audits pass. The self-test covers four of the screen-logic fixes.
- Release, debug and mirror firmware compile. Cppcheck finds no high or medium defects.
- **Checked on screen, not in motion.** The owner flashed this code on 2026-11-10 and confirmed boot, the reworked screens, the fault screen and the screen saver. Motion, pedal, calibration and TIG HF were not re-tested on this version. The last full machine test was v2.3.1 on 2026-11-04. No stop-time or calibration-accuracy measurements are claimed.

Check on your own machine after flashing:

1. Press E-STOP and confirm the red fault screen and that the motor is disabled. Release it and confirm the banner turns amber before you reset.
2. Start, change speed with the pot and with - / +, and stop.
3. Hold Jog in both directions for several seconds and confirm it does not drop.
4. Run a pedal start and release if you use a pedal.
5. Run one saved program and one calibration Move 360.

## Upgrade

Existing settings and programs are retained with the matching partition layout, and a standard application-image update is sufficient.
