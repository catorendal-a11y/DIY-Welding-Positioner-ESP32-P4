# v2.4.1 - Audit fixes

This release fixes 22 defects found in a code audit of the whole firmware. It requires no hardware changes. **This code has not been run on the machine. Native tests and firmware builds pass, but touch under TIG HF, fault reset, the speed floor and the USB mirror changed. Run the checks below on your own build before welding with it.**

## Changed on the machine

- **STOP acts on touch-down.** Every Stop button fires when it is touched, not only when the finger lifts. A press lost to touch read errors therefore still stops, and the lift can no longer land on a START that replaced STOP.
- **Open editors close when the status goes stale.** An input panel or the Step keypads close while the control status is unavailable, so the screen's Stop is visible. Typed but unconfirmed values are discarded.
- **USB mirror protocol v2.** A held remote press must be renewed by the viewer and expires after 150 ms. Viewers built before v2.4.1 are refused; rebuild the viewer.

## Fixed

- A touch read error during a held press no longer reports a release. Before, LVGL fired a click on the held button, and the next good read could press whatever button had appeared under the finger. A failed read now keeps the press for up to 150 ms and then cancels it without a click.
- A fault that latches while RESET TO IDLE is being processed is no longer erased by the reset. The reset is refused instead, and the fault stays on screen.
- After a reset, the next fault gets its own cleanup and log entry.
- A flash save no longer cancels a start that is waiting on the heartbeat gate.
- The lowest pot or pedal speed always converts to at least the start speed. On some roller and diameter combinations it rounded just below, and the minimum speed raised FAULT MOTOR COMMAND. 0 mHz is never sent to the driver.
- Re-enabling the pedal takes a fresh baseline instead of starting from the old pedal position.
- Erase data removes the old LittleFS settings and program files, so a corrupt legacy file can no longer bring the boot lockout back, and erased settings no longer return.
- Power glitch and CPU lockup resets show the UNEXPECTED RESET screen.
- The event log no longer drops FAULT and RESET entries when two tasks write at the same time.
- Screen strips skipped during a flash write are redrawn afterwards.
- USB mirror: logs no longer corrupt mirror frames, and the viewer requests a redraw after a damaged frame.
- Main shows the fault or range reason before a storage message.
- The stale-status banner is drawn above input panels.
- The Pulse screen re-reads and re-limits its speed.
- Display settings: the preview is no longer saved by an unrelated pending save.
- REBOOT warns that settings are unsaved while a failed save is retrying. It is not blocked, so a save that keeps failing cannot lock the restart.
- The setup wizard keeps its "motor saved" credit when Motor configuration is left during the save.
- About shows the current gear ratio.
- On-device storage tests back up and restore your settings and programs, and expect the correct NVS partition size.
- The native tests check the production clamp and touch-mapping code instead of hand copies.

## Known limits

- Pulse programs have no direction control. Set the direction in the Continuous or Step settings.
- Cancel during a pending program save leaves the editor but does not undo the save.
- An open E-STOP wire reads as healthy, and E-STOP acts through the MCU and the driver ENA input. It does not disconnect motor power.
- A floating pot wiper is not detected, and the analog pedal is not jump-checked.
- Early boot and panic output from the ESP-IDF ROM bypasses the mirror's log filter.

## Validation and hardware status

- **480 native/control/speed/storage/safety test cases** pass locally, including new regression tests for the touch hold, the fault reset race, the speed floor and legacy file removal.
- Release and mirror firmware compile, and the on-device test suites compile.
- The simulator was not rebuilt locally, and the About and System info captures still show v2.4.0. CI runs the simulator self-tests and layout audit.
- **Not tested on the machine.** The last full machine test was v2.3.1 on 2026-11-04. No stop-time or calibration-accuracy measurements are claimed.

Check on your own machine after flashing:

1. Press E-STOP and confirm the red fault screen and that the motor is disabled. Release it, reset, and confirm the machine returns to idle.
2. Start, change speed with the pot and with - / +, and stop. Turn the pot to its minimum while running and confirm the motor runs slowly without a fault.
3. With TIG HF active, hold Stop, Start and - / + and confirm each acts once.
4. Hold Jog in both directions for several seconds and confirm it does not drop.
5. Run a pedal start and release if you use a pedal, including after turning the pedal off and on.
6. Run one saved program and one calibration Move 360.
7. If you use the USB mirror, rebuild the viewer and check that a held remote jog stops when the viewer is closed.

## Upgrade

Existing settings and programs are retained with the matching partition layout, and a standard application-image update is sufficient. On first boot after a migration from LittleFS, the old files are removed once their contents are in NVS.
