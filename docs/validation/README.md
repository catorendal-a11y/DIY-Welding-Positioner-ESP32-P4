# Validation evidence

Logs record local native tests, firmware builds, simulator checks and device uploads. Workstation paths and the device MAC address are redacted; trailing whitespace is normalized. The ui-v5 directory contains the final V5 runs. Upload hash verification confirms flash contents. Physical motor and safety behavior require separate bench testing. These logs are dated records up to 2026-10-03. Later releases, including v2.3.0, rely on the CI run for the release commit.
