# V5 numeric font

rotator_digits_104.c is a 104 px, 4 bpp numeric subset of Montserrat Bold distributed with LVGL v9.5.0 (tests/src/test_files/fonts/Montserrat-Bold.ttf). Generated with lv_font_conv 1.5.3, no compression, glyphs 0123456789.-. License: SIL Open Font License; see OFL-Montserrat.txt. The source TTF stays in the pinned LVGL dependency. Both firmware and simulator compile the same generated C file. This avoids scaling a small raster font on the operator screen.

The generated font retains its original v9.5.0 provenance and OFL notice. Its compiled format has been verified with LVGL 9.6.0; the source TTF is also present in that pinned dependency.
